## Critérios para referências complementares

Uma referência adicional só é aceita para planejamento quando documentar, no mínimo:

- hierarquia, grid e densidade de conteúdo;
- comportamento de desktop, tablet e mobile;
- contraste entre conteúdo e cenário;
- estados de loading, vazio, erro, indisponibilidade e acesso negado quando aplicáveis;
- autoria/licença verificável quando for usada como fonte externa.

Referências externas são insumos de análise; não devem ser copiadas integralmente.
